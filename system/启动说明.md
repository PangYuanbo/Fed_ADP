# Fed_ADP 系统启动说明

## 系统架构概述

Fed_ADP是一个集成了联邦学习、差分隐私和成员推理攻击(MIA)的完整系统，支持CIFAR-10数据集的三种数据划分方式。

## 快速启动

### 使用预配置脚本（推荐）
```bash
# 运行带MIA评估的训练
sh run_with_mia.sh

# 基础训练
sh run_me.sh
```

### 手动启动命令

#### Windows 系统
```bash
python main.py -algo FedCP -data cifar-10-normal -m cnn -nc 20 -nb 10 -mia True
```

#### Linux 系统
```bash
python -u main.py -algo FedCP -data cifar-10-normal -m cnn -nc 20 -nb 10 -mia True
```

## 数据集说明

系统支持三种CIFAR-10数据集划分：

### 可用数据集
- `cifar-10-normal`：正常联邦学习数据集
- `cifar-10-shadow`：影子模型训练数据集（用于MIA攻击）
- `cifar-10-dp`：差分隐私训练数据集

### 数据集层级结构
```
dataset/
├── [alpha]/              # 不同α值的数据分布 (0.5, 0.7, 0.8, 1, 10)
│   ├── cifar-10-normal/
│   ├── cifar-10-shadow/
│   └── cifar-10-dp/
└── cifar-10-[type]/      # 默认数据集
```

## 主要参数说明

### 必需参数
- `-algo`：算法名称，必须为 `FedCP`
- `-data`：数据集名称（**新选项**：`cifar-10-normal`, `cifar-10-shadow`, `cifar-10-dp`）
- `-m`：模型类型（`cnn`, `resnet`, `fastText`）
- `-nc`：客户端总数（默认 20）
- `-nb`：类别数量（默认 10）

### MIA攻击相关参数（新增）
- `-mia`：是否启用MIA评估（默认 False）
- `-eg`：评估间隔轮数（默认 1，建议设为10以减少开销）

### 差分隐私相关参数
- `-dp`：是否启用差分隐私（默认 False）
- `-dpn`：差分隐私噪声参数（默认 5）
- `-dpl`：应用差分隐私的层（默认 "model.head"）

### 训练参数
- `-lr`：本地学习率（默认 0.005）
- `-gr`：全局训练轮数（默认 1000）
- `-ls`：本地训练步数（默认 1）
- `-lbs`：批次大小（默认 10）
- `-jr`：每轮参与的客户端比例（默认 1.0）
- `-al`：数据分布参数 alpha（默认 1）
- `-lam`：lambda 参数（默认 0.0）

### 系统参数
- `-dev`：设备类型（`cuda` 或 `cpu`，默认 cuda）
- `-did`：GPU 设备 ID（默认 "0"）
- `-t`：运行次数（默认 1）

## 示例命令

### 1. 基础联邦学习（正常数据集）
```bash
python main.py -algo FedCP -data cifar-10-normal -m cnn -nc 20 -nb 10 -gr 100
```

### 2. 启用差分隐私训练
```bash
python main.py -algo FedCP -data cifar-10-dp -m cnn -nc 20 -nb 10 -dp True -dpn 5 -dpl "model.head" -gr 100
```

### 3. 启用MIA攻击评估
```bash
python main.py -algo FedCP -data cifar-10-normal -m cnn -nc 20 -nb 10 -mia True -eg 10 -gr 100
```

### 4. 差分隐私 + MIA攻击组合
```bash
python main.py -algo FedCP -data cifar-10-dp -m cnn -nc 20 -nb 10 -dp True -dpn 5 -mia True -eg 10 -gr 100
```

### 5. 影子模型训练（用于MIA攻击）
```bash
python main.py -algo FedCP -data cifar-10-shadow -m cnn -nc 20 -nb 10 -gr 100
```

### 6. 使用不同Alpha值的数据分布
```bash
# 使用alpha=0.5的高度非IID数据
python main.py -algo FedCP -data 0.5/cifar-10-normal -m cnn -nc 20 -nb 10 -al 0.5

# 使用alpha=10的接近IID数据  
python main.py -algo FedCP -data 10/cifar-10-normal -m cnn -nc 20 -nb 10 -al 10
```

### 7. 使用ResNet模型
```bash
python main.py -algo FedCP -data cifar-10-normal -m resnet -nc 20 -nb 10 -mia True
```

### 8. 自定义训练参数
```bash
python main.py -algo FedCP -data cifar-10-normal -m cnn -nc 30 -nb 10 -lr 0.01 -gr 500 -lbs 32 -jr 0.5 -mia True
```

### 9. 指定GPU设备
```bash
python main.py -algo FedCP -data cifar-10-normal -m cnn -nc 20 -nb 10 -dev cuda -did 1 -mia True
```

### 10. CPU训练
```bash
python main.py -algo FedCP -data cifar-10-normal -m cnn -nc 20 -nb 10 -dev cpu -mia True
```

## MIA攻击模型管理

系统在`system/Membership_Inference_Attack/`目录下维护攻击模型：

### 攻击模型文件结构
```
Membership_Inference_Attack/
├── attack_model0.pth    # 类别0的攻击模型
├── attack_model1.pth    # 类别1的攻击模型
├── ...
└── attack_model9.pth    # 类别9的攻击模型
```

### 如果出现攻击模型缺失警告
```bash
# 运行MIA管道生成缺失的攻击模型
python Membership_Inference_Attack/run_mia_pipeline.py

# 或复制已训练的攻击模型
python utils/setup_mia_models.py --action copy --source ../Membership_Inference_Attack0
```

## 注意事项

1. **数据集准备**：确保数据集存在于正确路径
   - `dataset/cifar-10-normal/`：正常联邦学习数据
   - `dataset/cifar-10-shadow/`：影子模型训练数据
   - `dataset/cifar-10-dp/`：差分隐私训练数据
   - `dataset/[alpha]/cifar-10-[type]/`：特定α值的数据分布

2. **MIA攻击模型**：首次运行MIA时需要预训练攻击模型
   - 系统会自动检测并提示缺失的攻击模型
   - 建议先运行影子模型训练生成攻击模型

3. **GPU内存**：MIA评估会增加内存占用
   - 使用ResNet时建议减小批次大小
   - 设置`-eg 10`减少MIA评估频率

4. **算法支持**：当前只支持FedCP算法

5. **模型架构匹配**：
   - CIFAR-10数据集 → CNN模型（in_features=3）或ResNet
   - 确保数据集与模型架构匹配

6. **输出文件**：
   - 训练日志：实时打印到控制台
   - MIA结果：保存在`system/mia_results/`目录
   - 梯度日志：保存在`system/logs/`目录

## 常见问题

### Q: MIA攻击模型缺失
A: 运行`python Membership_Inference_Attack/run_mia_pipeline.py`或使用影子数据集先训练攻击模型

### Q: CUDA不可用  
A: 程序会自动切换到CPU，或手动指定`-dev cpu`

### Q: 内存不足
A: 减小批次大小`-lbs`、减少客户端数量`-nc`，或增大MIA评估间隔`-eg`

### Q: 训练太慢
A: 减少全局轮数`-gr`、增大评估间隔`-eg`，或禁用MIA评估

### Q: 数据集找不到
A: 检查`dataset/`目录结构，确保使用正确的数据集名称（如`cifar-10-normal`而不是`cifar10`）
